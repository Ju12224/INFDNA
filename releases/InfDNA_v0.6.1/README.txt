InfDNA v0.6.1 for Windows
-------------------------
1. Put these three files in one new folder: JOIN_ME.bat, InfDNA_v0.6.1.part1 and InfDNA_v0.6.1.part2.
2. Double-click JOIN_ME.bat. It joins the two parts, unzips the game and starts it.
   Windows may warn once: click More info, then Run anyway.
3. Later, start the game by double-clicking InfDNA.exe in that folder.
When you close the game it writes a report file: send it back.
